# 银月工坊：一镜到底录屏智能转录管家 (yinyue-screen-transcriber)

> **定位**：专为主人的读书一镜到底屏幕录制打造的【全自动抽音、智能切片、SayIt流式高精转录、双轨原稿归档、剪贴板无缝注入与桌面清理管家】。

---

## 🌟 核心功能特性

1. **零动手极简触发**：
   - 自动扫描桌面最新的 `屏幕录制 *.mp4`，主人录完无需手动改名或拖拽。
2. **FFmpeg 秒级音频分离**：
   - 毫秒级无损提取 16kHz 单声道 PCM 格式音频母带，保障后续语音模型最高识别精度。
3. **基于能量与静音的自然语义智能切片**：
   - 自动避开单词中间截断，在主人呼吸和停顿处（25s~45s）精准落刀，保证每一句语义的完整。
4. **SayIt 官方云端 ASR 引擎高速直连**：
   - 通过底层 WebSocket 直连 SayIt 官方流式转录内核，兼具云端高速与极高辨识度，同时产出【无删减原始 ASR】与【语感精修版】双轨文本。
5. **绝对防割裂·就地闭环归档（一盒端）**：
   - 录屏大视频、音频母带、全量逐字原稿统一归档至大本营目录；
   - 自动将桌面 1GB+ 庞大录屏移入，桌面瞬间恢复绝对洁癖；
   - 自动在 Obsidian 玉简对应书籍产出区生成同步镜像卡。
6. **剪贴板秒级注入与轻量 Toast 弹窗**：
   - 转录完成瞬间，自动将精修全文写入 Windows 剪贴板，主人切到 AI 对话框直接 `Ctrl + V` 粘贴；
   - 屏幕右下角自动弹出现代化轻量提示卡，展示字数与耗时，并配备 `[📂 打开逐字稿]` 与 `[📁 所在大本营]` 快捷按钮。
7. **工业级持久化三轨日志 (Logging Constitution)**：
   - `logs/latest_run.log`：单次全量流水账覆盖；
   - `logs/app_YYYY-MM.log`：按月滚动归档；
   - `logs/error.log`：异常黑匣子记录。

---

## 🚀 快速使用

- **一键运行**：双击根目录下的 `run.bat` 或在终端执行 `python scripts\transcriber.py`；
- **环境部署**：右键以 PowerShell 运行 `setup.ps1` 进行自检与解锁。
